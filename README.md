# SOOP 댓글 알림 필터

SOOP의 알림창에 **댓글만 / 전체** 필터를 추가하는 Chrome 확장 프로그램입니다. 댓글과 답글은 표시하고, 방송 시작·공지·구독·이벤트처럼 명확히 다른 알림은 `댓글만` 보기에서 숨깁니다. 종류가 모호한 알림은 놓치지 않도록 표시합니다.

## 폴더 구성

- `manifest.json`, `src/`, `icons/`: Chrome에 불러올 최신 확장 프로그램 (`1.0.5`)
- `test/`: 최신 소스의 자동 테스트
- `CONTEXT.md`: 실제 SOOP DOM과 구현 결정이 정리된 유지보수 문서
- `soop-comment-filter.zip`: 최신 배포본
- `archive/soop-comment-filter-v1.0.0/`: 비교·보관용 이전 버전이며 Chrome에 불러오지 않습니다.

확장 프로그램은 SOOP 서버 요청을 가로채거나 계정 정보를 저장하지 않습니다. 알림 항목을 삭제하지 않고 현재 페이지에서 CSS로만 숨기므로 `전체`를 누르면 즉시 원래 목록으로 돌아옵니다. 종 아이콘의 읽지 않은 알림 숫자도 변경하지 않습니다.

## 설치

1. 이 저장소 폴더를 내려받거나 압축을 풉니다.
2. Chrome 주소창에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 이 폴더의 `manifest.json`이 있는 디렉터리를 선택합니다.
6. 이미 열려 있던 SOOP 탭을 새로고침합니다.

## 사용법

SOOP에 로그인한 뒤 종 모양 알림 버튼을 누릅니다. 알림 목록 위에 날짜와 관계없이 전체 목록을 제어하는 필터가 한 번만 나타납니다.

- **댓글만**: 댓글, 답글, 그리고 종류를 확실히 판별하지 못한 알림을 표시합니다. 기본값입니다.
- **전체**: SOOP이 제공한 모든 알림을 표시합니다.

현재 필터에서 표시할 알림이 하나도 없는 날짜는 날짜 제목과 빈 목록을 함께 숨깁니다. `전체`로 전환하면 해당 날짜도 다시 나타납니다.

알림창이 닫혔다 다시 열리거나 페이지가 새로 로드되면 `댓글만`이 기본 선택됩니다.

## 지원 범위와 한계

- `https://www.sooplive.com/*`와 `https://*.sooplive.com/*`에서 동작합니다.
- SOOP가 알림창의 HTML 구조나 알림 문구를 크게 변경하면 필터가 나타나지 않거나 일부 알림을 다르게 분류할 수 있습니다.
- 현재 SOOP의 `ul.notification-module_list__…` 직계 `<li>`를 각각 하나의 알림으로 처리하며, CSS 모듈의 해시 접미사에는 의존하지 않습니다.
- 확장 프로그램을 비활성화하거나 삭제한 직후에는 열려 있던 SOOP 탭을 새로고침해야 삽입된 필터 UI가 완전히 제거됩니다.
- 알림 종류 판별 규칙은 `src/classifier.js`에서 관리합니다.

## 테스트

Node.js 18 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
npm test
```

실제 사이트에서는 로그인 후 다음을 확인합니다.

1. 알림창에 필터가 한 번만 표시되는지
2. 댓글과 답글이 `댓글만`에서 보이는지
3. 방송 시작, 공지, 구독, 이벤트 알림이 숨겨지는지
4. `전체` 선택 시 모든 알림과 기존 클릭 동작이 복원되는지
5. 더 보기 또는 스크롤로 추가된 알림에도 필터가 적용되는지

## 배포용 ZIP 만들기

저장소 루트에서 다음 명령을 실행하면 Git 정보와 테스트를 제외한 설치 파일을 묶을 수 있습니다.

```sh
zip -r soop-comment-filter.zip manifest.json src icons README.md CONTEXT.md
```

## 변경 이력

### 1.0.5 (2026-08-15)

- `게시글을 UP 했어요` 알림을 `댓글만` 보기에서 숨기도록 분류 규칙을 복구했습니다.
- 신규 게시글이나 UP 알림 제목에 `댓글`, `답글`이 포함돼도 댓글 알림으로 오분류되지 않도록 고정 알림 유형을 우선 판정합니다.

### 1.0.4 (2026-08-13)

- 페이지 전체의 `class`, `style`, `hidden`, `aria-hidden` 변경을 감시하던 전역 속성 observer를 제거했습니다.
- 알림 날짜 목록이 생성·교체되거나 해당 목록 안에 알림 `<li>`가 추가·삭제될 때만 재스캔하도록 범위를 제한했습니다.
- 방송 카드, 배너, 슬라이드 등 알림과 무관한 SOOP 화면 갱신에는 필터 탐색을 실행하지 않도록 최적화했습니다.
- 확장 자체 필터 UI 변경은 계속 observer 대상에서 제외하며 React 목록 교체 대응은 유지했습니다.
- observer 범위가 다시 넓어지는 것을 방지하는 회귀 테스트를 추가했습니다.

### 1.0.3 (2026-08-13)

- 확장이 삽입한 필터 UI와 자체 CSS 변경을 `MutationObserver`가 다시 처리하지 않도록 제외했습니다.
- 알림이 0개일 때 설정·정렬·빈 상태 영역을 알림 패널로 오인해 필터가 중복 생성되던 범용 탐색을 제거했습니다.
- 실제 `ul.notification-module_list__…`가 존재할 때만 필터를 생성하도록 탐색 범위를 제한했습니다.
- 실제 Chrome 연결을 통해 빈 알림 상태에서 필터가 세 곳에 생성되던 원인을 확인하고 회귀 테스트를 추가했습니다.
- 유지보수에 필요한 실제 DOM 구조와 구현 결정을 `CONTEXT.md`에 지속해서 기록하도록 정리했습니다.

### 1.0.2 (2026-07-21)

- SOOP의 실제 `ul.notification-module_list__… > li` 구조를 기준으로 알림 항목 탐색을 정확하게 변경했습니다.
- `신규 게시글`을 명확한 비댓글 알림으로 분류하도록 규칙을 보강했습니다.
- `댓글만` 필터에서 표시할 알림이 없는 날짜의 제목과 빈 목록을 자동으로 숨기도록 개선했습니다.
- `전체`로 전환하면 숨겨진 날짜와 알림을 모두 복원하도록 처리했습니다.
- 최신 소스는 저장소 루트에 유지하고 `1.0.0` 사본은 `archive/`로 분리했습니다.
- 버전 번호는 유지한 채 SOOP 공식 파비콘 기반 확장 프로그램 아이콘(16·32·48·128px)을 추가했습니다.

### 1.0.1 (2026-07-03)

- 날짜별 알림 목록마다 필터가 반복해서 나타나던 문제를 수정했습니다.
- 하나의 전역 `댓글만 / 전체` 필터가 모든 날짜의 알림을 함께 제어하도록 변경했습니다.
- SOOP의 기존 버튼 스타일과 충돌해 활성 필터의 글씨가 보이지 않던 문제를 수정했습니다.
- React가 알림 목록을 다시 렌더링할 때 필터가 중복 생성되지 않도록 보강했습니다.

### 1.0.0 (2026-06-27)

- Manifest V3 기반 Chrome 확장 프로그램을 처음 구현했습니다.
- SOOP 알림창에 `댓글만 / 전체` 필터를 추가했습니다.
- 댓글·답글, 비댓글, 판별 불가능 알림을 분류하는 독립적인 규칙 모듈을 추가했습니다.
- 동적으로 생성되거나 추가 로딩되는 알림을 `MutationObserver`로 처리했습니다.
- 알림을 삭제하지 않고 CSS로만 숨겨 기존 클릭·읽음·더 보기 동작을 유지했습니다.
- 자동 테스트, 설치·사용 설명서, 배포용 ZIP 구성을 추가했습니다.
